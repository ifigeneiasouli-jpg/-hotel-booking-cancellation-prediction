# Hotel Booking Cancellation Prediction

Machine Learning project developed as part of the course  
**"Artificial Intelligence Information Systems for Business"**  
at the University of Macedonia.

## Project Objective

The objective of this project was to improve the predictive performance of an existing machine learning model for hotel booking cancellations.

The analysis focuses on identifying whether a hotel reservation is likely to be cancelled based on historical booking data.

## Methodology

The project included:

- Data preprocessing and preparation
- Train-test data splitting
- Handling class imbalance
- XGBoost classification
- Hyperparameter tuning using RandomizedSearchCV
- Cross-validation
- Evaluation using Accuracy, Precision, Recall and F1-score
- Classification threshold analysis
- ROC curve analysis
- Feature importance analysis

## Notebook

The complete analysis and model development can be found in:

**hotel_booking_cancellation_prediction.ipynb**

## Dataset

The project uses hotel booking data originally derived from the  
**Hotel Booking Demand Dataset**.
